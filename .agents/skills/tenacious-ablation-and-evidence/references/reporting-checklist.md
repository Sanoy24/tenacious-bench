# Reporting Checklist

## Every benchmark claim should answer

- Compared against what?
- On which split?
- Using which evaluator?
- At what cost and latency?
- Where is the raw trace?

## Core outputs

- Delta A
- Delta B
- Delta C when applicable
- confidence interval or equivalent uncertainty view
- cost and latency delta

## Honesty rule

If a prompt-only baseline matches or beats the trained intervention, say so directly and interpret it carefully.
