# Path Formats

## Path A

Use high-quality chat-style input/output pairs. Keep prompts aligned with the production component you plan to replace or improve.

## Path B

Use chosen/rejected pairs. Track where each chosen answer came from and use a different model family for rewrites versus judging when possible.

## Path C

Use trajectories with step-level labels. Keep step boundaries explicit so the model learns process quality, not just end-state text.

## Shared rule

Preserve task IDs and filtering provenance across all paths.
