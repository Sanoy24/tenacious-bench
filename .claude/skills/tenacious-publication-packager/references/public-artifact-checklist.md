# Public Artifact Checklist

## Verify before publishing

- README is runnable
- datasheet has real content
- license is explicit
- attribution is clean
- links work
- seeds and reproduction notes are present
- held-out handling is described correctly

## Keep artifacts aligned

The README, blog, memo, and model card should not disagree on:

- baseline numbers
- model identity
- dataset version
- limits and caveats
