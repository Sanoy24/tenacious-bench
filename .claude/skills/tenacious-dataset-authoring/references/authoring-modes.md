# Authoring Modes

## Trace-derived

Best for high-fidelity tasks grounded in real agent behavior.

## Programmatic sweeps

Best for controlled coverage over structured variables.

## Multi-LLM synthesis

Best for generating hard or unusual variants, then filtering them aggressively.

## Hand-authored adversarial

Best for the sharpest grader-visible originality. Spend human effort here.

## Metadata rule

Record the source mode and seed artifact for every task. That traceability matters later in methodology and debugging.
